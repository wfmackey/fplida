Home Affairs Variable Code Evidence Register

Generated DHA/Home Affairs variables mapped to public sources, PLIDA metadata, and not-found evidence gaps

Published

June 16, 2026

1 Purpose

This register is the variable-level source audit for generated Department of Home Affairs products: AMEP, MT_DEMOGS, SDB, TRAVELLERS, and VISA.

The companion CSV, home-affairs-variable-code-evidence.csv, has one row per generated variable. It records the observed generated type and domain/distribution, the local PLIDA metadata or crosswalk match, the public source used where found, and whether the current generated values are source-equivalent, concept-only, or local synthetic evidence.

2 Use Rule

Use observed_generated_domain_or_distribution as the current fplida schema surface only. Do not use it as an official distribution unless evidence_status and source_summary say that an official source supports the same value domain.

Rows marked not_found, unverified, not_public, not_source_equivalent, or distribution_local are explicit blockers for future source-equivalent FPLIDA builds.

6 Source Notes

  • SDB rows use Home Affairs settlement reporting pages, reporting caveats, and the Settlement Database Data Dictionary. The dictionary supports settlement reporting concepts, but many generated compact values still require exact table-to-variable mapping before they are source-equivalent.
  • AMEP rows use the AMEP profile paper for program, tuition-hours, enrolment, and English-proficiency context. No public AMEP variable-level ASLPR codebook or generated-score distribution was found in this pass.
  • Visa, traveller, and migrant-demographics rows remain mostly local PLIDA/generator evidence. No public Home Affairs codebook was found for the generated visa subclass/reporting-group labels or the generated traveller 1/2/3 compact quarterly status encoding.
