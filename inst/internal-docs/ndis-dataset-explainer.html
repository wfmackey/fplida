5 Variable-level schema register

Every generated variable observed in this pass for this guide is listed in schema-registers/schema-register-ndis.csv. The register records R type, sampled generated missingness, sampled generated domains/distributions, and direct PLIDA metadata matches. Treat those sampled domains/distributions as implementation evidence only, not as official source data.

A rendered variable evidence appendix for this guide is available at variable-evidence-appendices/ndis-variable-evidence.qmd. It contains one row per generated variable with observed generated values or distributions, local metadata/crosswalk status, and unresolved-source caveats.

A stricter source-audited variable-code evidence register is available at ndis-variable-code-evidence.csv, with a rendered companion note at ndis-variable-code-evidence.qmd. Use that register to distinguish public NDIS concept support, local PLIDA/generator evidence, and generated labels/distributions that still need exact data-rule mapping.

Most generated NDIS fields in this compact product do not directly match local PLIDA metadata names. generated-variable-crosswalk.csv now maps the eight compact no-direct-match fields to same-dataset NDIS metadata variables. Those mappings establish local DIL concepts, not official source variable names or official category distributions.

7 Research uses and limits

The current product is useful for testing disability-service participation, plan-budget amounts, and linkage with other health/welfare datasets. It is not yet sufficient for detailed NDIS analysis of support-category utilisation, providers, payments, goals, or diagnosis until the additional metadata products are generated or linked.

8 Build implications

  1. Treat PLAN_BUDGET_AMT as a synthetic positive amount, not an official NDIS plan-budget distribution.
  2. Add direct code-label mapping for disability group, support category, and management type before publishing examples using those categories.
  3. Decide whether to add the other five metadata products before using NDIS as a major research-facing dataset in fplida examples.
