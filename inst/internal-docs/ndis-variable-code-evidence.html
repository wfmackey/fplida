NDIS Variable Code Evidence Register

Generated NDIS variables mapped to public sources, PLIDA metadata, and not-found evidence gaps

Published

June 16, 2026

1 Purpose

This register is the variable-level source audit for generated NDIS participant variables.

The companion CSV, ndis-variable-code-evidence.csv, has one row per generated variable. It records the observed generated type and domain/distribution, the local PLIDA metadata or crosswalk match, the public source used where found, and whether the current generated values are source-equivalent, concept-only, or local synthetic evidence.

2 Use Rule

Use observed_generated_domain_or_distribution as the current fplida schema surface only. Do not use it as an official distribution unless evidence_status and source_summary say that an official source supports the same value domain.

Rows marked unverified, need_mapping, not_public, or distribution_local are explicit blockers for future source-equivalent FPLIDA builds.

6 Source Notes

  • NDIS dataset pages support participant, plan-budget, utilisation, diagnosis, plan-management, support-category, and demographic concepts. They do not, by themselves, prove the generated compact categories or plan-budget distribution.
  • NDIS management-option guidance confirms self-management, plan management, and NDIA-management concepts. The generated labels Self, Plan, and Agency still need exact DIL/public data-rule mapping before they are treated as official labels.
