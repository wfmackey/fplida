Generated Schema Register

Variable-level current-output evidence for internal fplida dataset guides

Published

June 16, 2026

1 Purpose

generated-schema-register.csv is the current variable-level evidence table for the internal dataset explainers. It records the actual schema and sampled value domains/distributions produced by the current fplida generators.

This file should be treated as implementation evidence, not official real-world calibration evidence. Official codebooks, data dictionaries, and methodology sources still determine what a variable means in source data.

2 Register fields

Field Meaning
guide Internal guide family.
dataset Dataset or source group.
table Generated table/product sampled.
variable Generated column name.
type R class observed after reading generated output.
n_rows Number of sampled generated rows in the table.
missing, missing_pct Missingness in the sampled generated output.
distinct Number of distinct non-missing values in the sampled output.
domain_or_distribution For categorical fields, top observed values and counts; for numeric fields, min / p25 / median / p75 / max; for dates, min to max.
values_if_small_domain Full observed value list when the sampled domain is small enough to display.
metadata_match Whether the variable matched local PLIDA metadata by dataset + variable.
plida_variable_descriptions, plida_products Local PLIDA metadata descriptions/products where a direct match was found.
blade_item, blade_valid_response, blade_available_periods Local BLADE metadata fields where a BLADE variable-name match was found.

6 Source hierarchy

Use the following hierarchy when revising the dataset explainers:

  1. Official source data dictionary, methodology, or codebook.
  2. Local PLIDA/BLADE metadata files under inst/plida_metadata/ and inst/blade_metadata/.
  3. Current generator output in generated-schema-register.csv.
  4. Generator code/tests/foundation assumptions.
  5. If none of the above exists, state that the source was not found.

Do not present sampled generated values as official source-data distributions.

8 Revision rule

Every dataset explainer should now include either:

  1. a compact table of key variables plus a link to generated-schema-register.csv; or
  2. a full appendix table derived from generated-schema-register.csv for that guide.

The guide prose should not assert category domains, distributions, weights, or coverage unless those values are explicitly present in the register, in local metadata, or in an official source.
