5 Variable-level schema register

Every generated variable observed in this pass for this guide is listed in schema-registers/schema-register-vet-apprentice.csv. The register records R type, sampled generated missingness, sampled generated domains/distributions, and direct PLIDA metadata matches. Treat those sampled domains/distributions as implementation evidence only, not as official source data.

A rendered variable evidence appendix for this guide is available at variable-evidence-appendices/vet-apprentice-variable-evidence.qmd. It contains one row per generated variable with observed generated values or distributions, local metadata/crosswalk status, and unresolved-source caveats.

A stricter source-audited variable-code evidence register is available at vet-apprentice-variable-code-evidence.csv, with a rendered companion note at vet-apprentice-variable-code-evidence.qmd. Use that register to distinguish AVETMISS public source support, local PLIDA/generator evidence, apprentice-codebook-not-found rows, and generated domains that need format tightening.

Dataset Generated variable rows Direct PLIDA metadata matches No direct PLIDA name match
A&T 14 8 6
TVA 74 74 0

Rows without a direct PLIDA match need a generated-name to DIL-name crosswalk before they are treated as source variables. For VET, the AVETMISS material is the stronger source for TVA element definitions; apprentice/trainee compact fields still need direct code-list evidence.

8 Research uses and limits

TVA is suitable for testing VET course/activity/completion workflows and geographic/provider joins. The apprentice product is suitable for simple apprenticeship-status examples, but not yet a full substitute for official apprentice/trainee collections.

9 Build implications

  1. Use NCVER AVETMISS documentation to add code labels for TVA values before user-facing examples interpret them.
  2. Keep TVA training activity and completions as separate tables; do not infer completions from activity outcome codes without a documented rule.
  3. Expand A&T only after sourcing official apprentice/trainee variable and status definitions.
