DSS Variable Code Evidence Register

Generated DOMINO and DEX variables mapped to public sources, PLIDA metadata, and not-found evidence gaps

Published

June 16, 2026

1 Purpose

This register is the variable-level source audit for generated DSS products: DOMINO and DEX.

The companion CSV, dss-variable-code-evidence.csv, has one row per generated variable. It records the observed generated type and domain/distribution, the local PLIDA metadata or crosswalk match, the public source used where found, and whether the current generated values are source-equivalent, concept-only, or local synthetic evidence.

2 Use Rule

Use observed_generated_domain_or_distribution as the current fplida schema surface only. Do not use it as an official distribution unless evidence_status and source_summary say that an official source supports the same value domain.

Rows marked not_found, unverified, not_source_equivalent, or distribution_local are explicit blockers for future source-equivalent FPLIDA builds.
