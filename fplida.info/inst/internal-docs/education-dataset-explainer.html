5 Variable-level schema register

Every generated variable observed in this pass for this guide is listed in schema-registers/schema-register-education.csv. The register records R type, sampled generated missingness, sampled generated domains/distributions, and direct PLIDA metadata matches. Treat those sampled domains/distributions as implementation evidence only, not as official source data.

A rendered variable evidence appendix for this guide is available at variable-evidence-appendices/education-variable-evidence.qmd. It contains one row per generated variable with observed generated values or distributions, local metadata/crosswalk status, and unresolved-source caveats.

A stricter source-audited variable-code evidence register is available at education-variable-code-evidence.csv, with a rendered companion note at education-variable-code-evidence.qmd. Use that register to distinguish TCSI/AEDC public source support, local PLIDA/generator evidence, and fields where exact data-element mapping or scoring evidence is still missing.

6 Higher education generated schema and domains

The official HE source describes the administrative collection and key variables such as course, institution, age, gender, citizenship, Aboriginal and Torres Strait Islander status, location, basis of admission, attendance type, attendance mode, country of birth, language, and year of arrival. The tables below record the current local generator schema.

7 AEDC generated schema and domains

The official AEDC source identifies five domains: physical health and wellbeing, social competence, emotional maturity, language and cognitive skills, and communication skills/general knowledge. The local generator writes compact domain-score records for children aged about 4 to 6 in each cycle.

Variable Type Expected values or distribution Evidence
SYNTHETIC_AEUID Character ID DE agency person key. Local smoke output
GENDER Categorical Local generated domain Male, Female. Local Rust/smoke
AGEINMONTHS Integer Local generator targets age 4 to 6 at cycle year, expressed in months. Local Rust
STATE Integer/code State/territory from spine. Local generator
ATSI, LBOTE, SPECIALNEEDS Categorical Local generated domain Yes, No. Local Rust/smoke
SCHOOLTYPE Categorical Local domain Government, Catholic, Independent with local weights 0.65/0.20/0.15. Local Rust
REMOTENESS Integer/code Local domain 1 to 5 with local weights 0.65/0.20/0.10/0.03/0.02. Local Rust
SEIFADECILE Integer Local generated range 1 to 10. Local Rust
CYCLE Integer Requested AEDC cycle year. Defaults: 2009, 2012, 2015, 2018, 2021. Local R wrapper
PHYS, SOC, EMOT, LANGCOG, COMGEN Numeric Local score range 0 to 10, rounded to two decimals. Local Rust
PHYSCATEGORY, SOCCATEGORY, EMOTCATEGORY, LANGCOGCATEGORY, COMGENCATEGORY Categorical Local domain Vulnerable, At risk, On track; local cutoffs are <4.5, <6.0, otherwise on track. Local Rust
DV1, DV2 Integer flag DV1 = 1 if vulnerable on 1+ domains; DV2 = 1 if vulnerable on 2+ domains. Local Rust

Unresolved AEDC gap: the generator comments approximate 10% vulnerable and 15% at risk shares, but this pass did not verify official percentile cutoffs or cycle-specific cut scores. Do not use those shares as official calibration targets until sourced.

8 Research uses and limits

HE can support tertiary-education spell examples, HELP exposure, course-load logic, and links to later earnings outcomes. AEDC can support early-childhood development examples. Both need official code-label crosswalks before research-facing tables interpret numeric category codes.

9 Build implications

  1. Add codebook metadata for HE category labels before promoting HE examples.
  2. Decide whether AEDC 2024 should be added to the default cycle list; current generator defaults stop at 2021 even though recent official reporting includes 2024.
  3. Keep AEDC domain scores clearly marked as synthetic local scores unless cycle-specific AEDC scoring documentation is linked.
