### on\_sato\_vet\_cd

<br>**Form**:  
Individual Tax Return  
<br>**Section**:  
Tax Offsets  
<br>**Question**:  
Senior Australians (includes age pensioners, service pensioners and
self-funded retirees)  
<br>**Label**:  
Senior Australian tax offset code for veterans  
<br>**General Notes**:  
Senior Australian tax offset claim code type for veterans, first
reported in 2002.   

<br>**Latest or Current Conditions**:  
Latest year: 2011-12. This variable refers to the tax offset code used
to calculate the senior Australian tax offset if the taxpayer or the
spouse was a veteran, war widow, or war widower.  
  
*Code Definition*  
**V:** Veteran, war widow or war widower.  
**W:** Spouse was a veteran, war widow or war widower.  
**X:** Both V and W apply.  
   

<br>**Latest or Current Calculations**:  
Latest year: 2011-12. If the veteran code letter applies, print the code
letter in the VETERAN CODE box. Otherwise, leave blank.   

<br>**Earliest Conditions**:  
For 2001-02, this variable refers to pensions tax offset code letter
used to work out the senior Australian tax offset.  
  
*Code Definition*  
**V:** Veteran, war widow or war widower.  
**W:** Spouse was a veteran, war widow or war widower.  
**X:** Both V and W apply.  
   

<br>**Earliest Calculations**:  
For 2001-02, print the veterans tax offset code.
